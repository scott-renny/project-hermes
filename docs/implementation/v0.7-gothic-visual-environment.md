# Project Hermes v0.7 Gothic Visual Environment

The v0.7 visual environment is a functional Rainmeter interpretation of the gothic command-center mockup. The Windows taskbar remains the only taskbar; the decorative hotkey strip from the concept is intentionally omitted.

## Layout

- Left: `HermesLauncher`, a categorized application and COC launcher.
- Upper right: `HermesClock` followed by `HermesPerformance`.
- Lower right: `HermesAgenda` and `HermesNotes`.
- Lower left: `HermesIdentity`.
- Center: `assets/wallpapers/hermes-gothic-command-center-wallpaper-v1.png`.

Every Hermes Rainmeter skin uses the desktop layer through `OnRefreshAction=[!ZPos -2]`. Windows and applications therefore open above the panels.

## Launcher choices

The launcher includes Discord, Slack, Telegram, Outlook, LibreOffice, Notepad++, Obsidian, VS Code, Windows Terminal, Everything, Bitwarden, Windows Settings, and Task Manager.

COC access includes:

- `wt.exe ssh coc-srv-01` for public-key SSH.
- VS Code Remote SSH to `/home/scott/coc-engineering-program`.
- Windows VPN settings.
- Configurable NetWatch, Wazuh, Caddy, and command-dashboard addresses.

Private dashboard addresses are deliberately not committed. Set them in the installed `HermesLauncher/HermesLauncher.settings.psd1`. An unconfigured or unavailable action now displays a useful message instead of failing silently.

All launcher buttons call `HermesLauncher/Invoke-HermesLauncher.ps1`. The resolver checks installed application locations, uses the permanent Project Hermes repository, opens COC runbooks and policies in the authoritative engineering-program repository, and supports public-key SSH through the `coc-srv-01` SSH alias. The VPN button opens Windows VPN settings. The Recycle button opens the native Recycle Bin.

## Editable content

- Right-click the launcher and select **Edit Hermes launcher settings** to edit the SSH host, remote path, browser, and private dashboard addresses.
- Double-click the Notes body to edit `HermesNotes/Notes.inc`, save the file, and refresh the skin.
- Agenda priorities remain editable from the Agenda skin's context menu.

## Installation

Copy the contents of `assets/rainmeter` into the active Rainmeter `Skins` directory so that `@Resources` and each `Hermes*` folder share the same parent. Refresh Rainmeter, load the desired skins, position them, and save the layout.

The repository installer performs this operation repeatably:

```powershell
& .\scripts\Install-HermesRainmeter.ps1
```

## Lock screen

Hermes uses separate gothic gate artwork for the portable lock screen. Preview the change, then apply it from an elevated PowerShell window:

```powershell
& .\scripts\customization\Set-HermesLockScreen.ps1 -WhatIf
& .\scripts\customization\Set-HermesLockScreen.ps1
```

The script validates the image, backs up the current Personalization CSP values under `exports/backups/lockscreen`, and reports when elevation is required. Sign out or lock Windows after applying it to verify the result.

Windows 11 does not provide a supported live lock screen. Hermes therefore keeps the secure Windows lock surface static. The experimental animated pre-lock overlay was removed after it caused graphics instability during validation.
