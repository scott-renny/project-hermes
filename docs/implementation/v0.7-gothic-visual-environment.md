# Project Hermes v0.7 Gothic Visual Environment

The v0.7 visual environment is a functional Rainmeter interpretation of the gothic command-center mockup. The Windows taskbar remains the only taskbar; the decorative hotkey strip from the concept is intentionally omitted.

## Layout

- Left: `HermesLauncher`, a categorized application and COC launcher.
- Upper right: `HermesClock` followed by `HermesPerformance`.
- Lower right: `HermesAgenda` and `HermesNotes`.
- Lower left: `HermesIdentity`.
- Center: `assets/wallpapers/hermes-gothic-command-center-wallpaper-v1.png`.

Every Hermes Rainmeter skin uses the desktop layer through `OnRefreshAction=[!ZPos -2]`. Windows and applications therefore open above the panels.

## Launcher choices

The launcher includes Discord, Slack, Telegram, Outlook, LibreOffice, Notepad++, Obsidian, VS Code, Windows Terminal, Everything, Bitwarden, Windows Settings, and Task Manager.

COC access includes:

- `wt.exe ssh coc-srv-01` for public-key SSH.
- VS Code Remote SSH to `/home/scott/coc-engineering-program`.
- Windows VPN settings.
- Configurable NetWatch, Wazuh, Caddy, and command-dashboard addresses.

Private dashboard addresses are deliberately not committed. Set them in `assets/rainmeter/@Resources/HermesVisual.inc` after installing the skins. Empty values leave the corresponding buttons inactive.

## Editable content

- Right-click the launcher and select **Edit Hermes launcher settings** to edit application paths and private dashboard addresses.
- Double-click the Notes body to edit `HermesNotes/Notes.inc`, save the file, and refresh the skin.
- Agenda priorities remain editable from the Agenda skin's context menu.

## Installation

Copy the contents of `assets/rainmeter` into the active Rainmeter `Skins` directory so that `@Resources` and each `Hermes*` folder share the same parent. Refresh Rainmeter, load the desired skins, position them, and save the layout.
